**This is the streaming in chatbot**

The problem is that when a big message is to be generated, users wait until the full response shown up in the webpage. This is what has been implemented in the previous workflow. 
But for the case of chatgpt and other chat toolbox, messages are being printed word by word, and user can see the ongoing process. 

We will implement that streaming method in our pipeline. 

- if we implement streaming then we can see step by step activity done by the ai agent. 
- it is very important to calm the user. 
- good for debuging while generation is in process.
